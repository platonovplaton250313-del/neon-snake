# NEON SNAKE

Неоновая змейка с мини-играми, бонусами, игрой против ботов и сетевой игрой.
Есть две версии:

- **Мобильная PWA** для Android и iPhone — открывается в браузере и ставится на
  главный экран, работает офлайн (кроме сетевого режима).
- **Windows-версия** — готовый `.exe`, Python и сторонние библиотеки не нужны.

- Исходники: <https://github.com/platonovplaton250313-del/neon-snake>
- Готовые сборки: <https://github.com/platonovplaton250313-del/neon-snake/releases>
- Мобильная версия: <https://platonovplaton250313-del.github.io/neon-snake/>

---

## Мобильная версия (Android и iPhone)

Откройте <https://platonovplaton250313-del.github.io/neon-snake/> в браузере телефона.

**Android (Chrome):** меню `⋮` → «Установить приложение» или «Добавить на главный
экран». **iPhone (Safari):** «Поделиться» → «На экран "Домой"».

После первого запуска игра кэшируется и работает без интернета. Интернет нужен
только для сетевого режима. Настройки и рекорды хранятся на устройстве.

Мобильная версия — это те же шесть режимов, неоновая графика, бонусы, золотые
звёзды и отдельные рекорды по режимам. Управление: свайп по полю, экранный
D-pad или стрелки клавиатуры.

## Установка на любой компьютер

Нужен Windows 10 версии 1803 или новее (в нём уже есть `curl` и `tar`).
В Windows нет встроенной команды `install`, поэтому первый раз нужна одна короткая
строка — она скачивает крошечный скрипт-установщик:

```bat
curl -L -sS -o install.cmd https://github.com/platonovplaton250313-del/neon-snake/releases/latest/download/install.cmd
```

Теперь в том же окне CMD выполните:

```bat
install snake
```

Скрипт скачает установщик (~22 МБ), распакует его и установит игру. После установки
откройте **новое** окно CMD (старые не видят обновлённый `PATH`) и введите:

```bat
snake
```

### Если не хочется скачивать скрипт

Можно установить одной длинной командой — результат тот же:

```bat
curl -L -o "%TEMP%\ns.tgz" https://github.com/platonovplaton250313-del/neon-snake/releases/latest/download/NeonSnakeSetup.tar.gz && tar -xzf "%TEMP%\ns.tgz" -C "%TEMP%" && "%TEMP%\NeonSnakeSetup.exe" --install
```

Можно также передать другому человеку файл `dist\install.cmd` (2 КБ): положите его
в любую папку, откройте там CMD и введите `install snake`.

Сам `dist\NeonSnakeSetup.exe` тоже можно просто запустить двойным кликом — он
установит игру, добавит команды и покажет подсказку в конце.

### Если `snake` не находится

1. Закройте и откройте CMD заново.
2. Проверьте: `where snake` — должна быть строка в
   `%LOCALAPPDATA%\NeonSnake\bin\snake.cmd`.
3. Если установщик не смог изменить `PATH`, запускайте игру по полному пути:
   `%LOCALAPPDATA%\NeonSnake\NeonSnake.exe`. Повторный `install snake` попробует
   добавить `PATH` ещё раз.

### Предупреждение SmartScreen

Файл не подписан цифровой подписью, поэтому Windows может показать синее окно
«Windows защитила ваш компьютер». Нажмите **«Подробнее» → «Выполнить в любом случае»**.
Это стандартное поведение для новых безподписных программ.

## Команды после установки

| Команда | Что делает |
| --- | --- |
| `snake` | запускает игру без окна консоли |
| `install snake` | переустанавливает / восстанавливает игру из сохранённого установщика |
| `install snake --remove` | удаляет игру (сохранения и рекорды остаются) |

`install snake` полезен, если файлы игры случайно изменили или удалили: установщик
сверяет контрольные суммы и возвращает всё в исходное состояние. Интернет для
восстановления не нужен — установщик уже лежит в папке игры.

Чтобы получить новую версию игры, снова скачайте `install.cmd` в любую папку и
выполните `install snake` **в этой же папке** — bootstrap загрузит свежий установщик.

## Куда всё ставится

| Что | Где |
| --- | --- |
| Файлы игры | `%LOCALAPPDATA%\NeonSnake\` |
| Команды `snake` / `install` | `%LOCALAPPDATA%\NeonSnake\bin\` |
| Сохранения, настройки, рекорды | `%APPDATA%\NeonSnake\neon_snake_save.json` |
| Журнал ошибок | `%APPDATA%\NeonSnake\neon_snake_error.log` |

При установке старые сохранения из папки, откуда запускался установщик,
переносятся автоматически.

## Защита от изменения кода

- Игра поставляется **только в виде скомпилированного `.exe`** — исходного кода
  Python в установленной папке нет.
- Файлы игры и установщика получают атрибут «только чтение».
- `manifest.json` хранит SHA-256 и размеры файлов. `install snake` проверяет их и
  при расхождении восстанавливает игру из встроенной копии.
- Установщик не требует прав администратора и ставит игру в профиль пользователя.

Ограничение: это защита от случайного или бытового редактирования, а не DRM.
Администратор компьютера в принципе может удалить файлы или обойти проверку.
Абсолютной защиты на чужом ПК не существует.

**В меню**

| Клавиши | Действие |
| --- | --- |
| `↑` / `↓` | выбрать пункт |
| `Enter` | открыть |
| `Esc` | выход |

**В мини-играх и настройках**

| Клавиши | Действие |
| --- | --- |
| `↑` / `↓` | выбрать строку или режим |
| `←` / `→` | изменить значение настройки |

| `Esc` | назад |

**В игре**

| Клавиши | Действие |
| --- | --- |
| `← ↑ → ↓` или `W A S D` | движение |
| `ПРОБЕЛ` / `P` | пауза (кроме сетевой игры) |
| `R` | начать заново (кроме сетевой игры) |
| `M` | мини-игры (на экране проигрыша) |
| `Esc` | меню |

## Режимы

| Режим | Что это |
| --- | --- |
| `КЛАССИКА` | обычная змейка: яблоки, комбо, золотые звёзды, бонусы |
| `ЛАБИРИНТ` | каждый забег на поле вырастают неоновые стены — нужен обход |
| `БЛИЦ 60` | одна минута на всё; змейка быстрее, комбо короче, время в HUD |
| `ХАОС` | метеориты, турбо-ускорения и звездопады — арена не даёт расслабиться |
| `ПРОТИВ БОТОВ` | две змеи-ИИ собирают яблоки на том же поле; боты respawn после аварии |
| `СЕТЕВАЯ ИГРА` | два живых игрока по коду комнаты (PWA) или по локальной сети (`.exe`), матч на 90 секунд |

У каждого режима свой рекорд. На экране проигрыша `M` возвращает к выбору мини-игры.

## Сетевая игра в мобильной версии

Играть можно с телефона, планшета или компьютера в браузере. Хост создаёт
комнату, получает код из пяти символов и передаёт его второму игроку. Гость
вводит код — матч начинается автоматически.

Соединение идёт через публичные MQTT-брокеры по WebSocket: первый символ кода
выбирает брокер (`A` — EMQX, `B` — HiveMQ). Интернет нужен обоим игрокам. Матч
длится 90 секунд, хост авторитетно симулирует обе змеи, гость отправляет только
направление. Побеждает тот, кто набрал больше очков; если один разбился, матч
заканчивается. Бонусы в сети отключены, золотые звёзды остаются.

Мобильная версия несовместима с `.exe`-версией: там другой протокол (TCP по
локальной сети). Если соединение не устанавливается, проверьте интернет и
попробуйте создать комнату ещё раз — код с другой первой буквой выберет второй
брокер. Публичные брокеры бесплатные и иногда перегружены: если матч зависает,
вернитесь в меню и создайте комнату заново.

## Сетевая игра в .exe-версии (локальная сеть)

Оба компьютера должны быть в одной локальной сети (Wi-Fi или кабель).
Сторонние библиотеки и интернет не нужны — используется обычный TCP.

**На первом компьютере (хост):**

1. `МИНИ-ИГРЫ` → `СЕТЕВАЯ ИГРА` → `СОЗДАТЬ ИГРУ (ХОСТ)`.
2. На экране появится адрес вида `192.168.1.50:45871` — передайте его второму игроку.

**На втором компьютере (гость):**

1. `МИНИ-ИГРЫ` → `СЕТЕВАЯ ИГРА` → `ПОДКЛЮЧИТЬСЯ`.
2. Введите IP-адрес хоста. Порт можно указать через двоеточие: `192.168.1.50:45871`.
3. Если порт не указан, используется `45871`.

Матч длится 90 секунд. Хост авторитетно симулирует обе змеи, гость отправляет
только направление движения. Побеждает тот, кто набрал больше очков; если один
игрок разбился, матч сразу заканчивается. Бонусы в сетевом матче отключены для
честности, золотые звёзды остаются. Пауза и `R` в сетевом режиме отключены,
чтобы не рассинхронизировать игру. `Esc` — выход в меню и разрыв соединения.

Если Windows спросит про доступ к сети для `NeonSnake.exe`, разрешите его для
частных сетей. Если подключиться не удалось, проверьте IP, порт и брандмауэр;
иногда помогает отключить VPN на обоих компьютерах.

## Бонусы на поле

Шестиугольные бонусы появляются по мере сбора яблок и живут около 9 секунд:

| Значок | Бонус | Эффект |
| --- | --- | --- |
| `Щ` | Щит | 7 секунд неуязвимости: стены, хвост и даже край поля не страшны |
| `×2` | Двойные очки | 10 секунд удвоения очков за яблоки и звёзды |
| `З` | Замедление | 8 секунд более спокойного темпа |

Активные эффекты и их таймеры видны внизу экрана. В режиме `ХАОС` дополнительно
случаются события: `МЕТЕОРИТЫ!` (опасные клетки на время), `ТУРБО!` (рывок скорости)
и `ЗВЕЗДОПАД!` (внеочередная золотая звезда).

## Настройки

Экран настроек открывается из главного меню:

- **Скорость** — медленно / обычно / быстро (меняет начальный темп и разгон).
- **Стены** — смертельные или телепорт сквозь край поля.
- **Сетка** — показывать или скрыть разметку клеток.
- **Частицы** — взрывы, кольца и искры.
- **Тряска экрана** — отдача от событий.
- **Звук** — системные сигналы Windows (по умолчанию выключен).
- **Золотая звезда** — как часто появляется: редко / обычно / часто.
- **Сбросить рекорды** — двойное подтверждение через `Enter`.

Настройки сохраняются автоматически.

## Что внутри

- Плавное скольжение змейки между клетками и плавные повороты.
- Неоновое свечение, градиент от головы к хвосту, глаза и язык.
- Пульсирующие яблоки, взрывы частиц, расходящиеся кольца, тряска экрана.
- Комбо: если собирать яблоки подряд (до 5 штук), очки умножаются.
- Золотая звезда: +30 очков, но исчезает — вокруг неё тает таймер.
- Бонусы с таймерами, метеоритная арена и события в режиме «Хаос».
- Скорость растёт вместе с длиной змейки (индикатор в HUD).
- Игра против двух ботов: ИИ ищет еду через BFS, обходит препятствия и respawn
  после аварии; счёт ботов виден в HUD.
- Сетевая игра: хост-авторитетная симуляция, отдельные цвета и имена змей.
  В PWA — через MQTT/WebSocket и код комнаты, снимки ~10 раз в секунду;
  в `.exe` — по локальной сети, ~20 раз в секунду.
- Статистика забега на экране проигрыша: яблоки, звёзды, бонусы, максимальное комбо.
- Рекорды по режимам и настройки сохраняются между запусками.
- Игра сама ставится на паузу, если переключиться в другое окно (кроме сети).

## Для разработчика

Исходники лежат в папке проекта; для запуска нужен Python 3.8+ с `tkinter`:

```bat
python neon_snake.py
```

Сборка обоих `.exe` (нужен `pyinstaller`):

```bat
python -m pip install pyinstaller
python installer\build.py
```

Результат:

| Файл | Назначение |
| --- | --- |
| `dist\NeonSnake.exe` | сама игра, окно без консоли |
| `dist\NeonSnakeSetup.exe` | установщик с встроенной игрой |
| `dist\install.cmd` | bootstrap-скрипт для первой установки |

Иконка генерируется скриптом `installer\make_icon.py` в `assets\neon_snake.ico`.

Старые файлы `install_snake.cmd`, `snake.cmd`, `play.bat`, `play_silent.bat` и
`uninstall_snake.cmd` — это прежний запуск из исходников. Для установленной
`.exe`-версии они не нужны.

### Публикация новой версии

1. Соберите `python installer\build.py`.
2. Создайте архив установщика:

   ```bat
   tar -czf dist\NeonSnakeSetup.tar.gz -C dist NeonSnakeSetup.exe
   ```

3. Обновите `dist\install.cmd` из `installer\bootstrap.cmd` и создайте релиз на
   GitHub с четырьмя файлами:

   ```bat
   copy installer\bootstrap.cmd dist\install.cmd
   gh release create v1.2.0 dist\NeonSnake.exe dist\NeonSnakeSetup.exe ^
       dist\NeonSnakeSetup.tar.gz dist\install.cmd
   ```

   Ссылки в `installer\bootstrap.cmd` и README используют
   `releases/latest/download/...`, поэтому при выпуске новой версии их менять
   не нужно — достаточно приложить новые файлы к свежему релизу.

4. Если менялся сам bootstrap, замените ассет в текущем релизе:

   ```bat
   gh release upload v1.2.0 dist\install.cmd --clobber
   ```

5. Проверьте установку на чистом профиле:
   `set NEON_SNAKE_HOME=%TEMP%\test-home` и
   `set NEON_SNAKE_DATA=%TEMP%\test-data` перед запуском установщика.

### GitHub Pages (мобильная версия)

Мобильная PWA лежит в `docs/` и публикуется без сборки:

1. В настройках репозитория: **Settings → Pages → Source: Deploy from a branch**,
   ветка `main`, папка `/docs`.
2. Сайт: <https://platonovplaton250313-del.github.io/neon-snake/>.
3. После изменений в `docs/` обновите версию кэша в `docs/sw.js`
   (`const CACHE = 'neon-snake-vN'`) и отправьте изменения в `main`.
