# CHESS ARENA — шахматы

Веб-версия и исходники интерфейса лежат в `docs/chess/`, а Windows-обвязка
(запуск, установка и сборка) — в `chess-arena/`.

Это отдельная шахматная игра в духе Chess.com:

- игра против компьютера (**6 уровней**, от новичка ≈800 до мастера 2400, плюс
  уровень «Своя» с настраиваемым диапазоном силы) или вдвоём на одном устройстве;
- **Stockfish 16** (single-threaded WASM) для игры и разбора: честная сила через
  `UCI_Elo`, поэтому 1600 играет заметно сильнее 500, а 2400 — сильнее 2000;
  встроенный движок остаётся запасным и работает офлайн;
- контроль времени: 10 + 0, 5 + 3, 3 + 2, 1 + 0 или без часов, с инкрементом;
- полные правила: рокировка, взятие на проходе, превращение пешки, мат, пат,
  троекратное повторение, правило 50 ходов и недостаток материала;
- перетаскивание и выбор кликом, подсветка допустимых ходов, история партии
  с просмотром, отмена хода, переворот доски, звуки и стрелка лучшего хода;
- **расширенные настройки**: 5 тем доски, 3 стиля фигур, размер фигур,
  координаты, подсветка ходов, скорость анимации, громкость, автопревращение,
  подтверждение сдачи, шкала оценки и диапазон силы бота «от и до»;
- **разбор партии после финала**: оценка каждой позиции Stockfish, график,
  точность, лучшие ходы, шкала оценки и пометки «неточность», «ошибка», «зевок»;
- **архив партий**: последние 40 партий сохраняются на устройстве, любую можно
  открыть, просмотреть и разобрать;
- **PGN и FEN**: копирование, скачивание `.pgn`, загрузка PGN или FEN позиции;
- **тактические задачи**: 15 классических позиций и бесконечный генератор
  с четырьмя уровнями — мат в 1, вилка конём, жертва на последней горизонтали
  и экспертный форсированный мат в 2; новые задачи создаются каждый раз,
  проверяются правилами и движком;
- статистика решённых задач, серии и прогресс по уровням сохраняются в браузере;
- адаптивная вёрстка для телефона и офлайн-кэш PWA.

Движок Stockfish распространяется по лицензии GPLv3; текст лицензии и источник
лежат в `docs/chess/js/stockfish/COPYING.txt`.

Открыть в браузере: <https://platonovplaton250313-del.github.io/neon-snake/chess/>

Один файл без сервера и интернета: `docs/chess/standalone.html` — откройте
двойным кликом.

### Запуск через CMD

Откройте CMD в папке `chess-arena` (или в распакованном архиве `ChessArena`)
и выполните:

```bat
chess
```

Из корня репозитория игру можно запустить так:

```bat
chess-arena\chess.cmd
```

`chess.cmd` запускает маленький локальный сервер на `127.0.0.1`, открывает
браузер и не требует прав администратора. Окно сервера можно свернуть; закройте
его, чтобы остановить игру. Если порт `8137` занят, будет выбран следующий
свободный. Можно указать порт вручную:

```bat
chess -Port 8145
```

Проверить, что именно запустится, без запуска сервера:

```bat
chess -Check
```

### Установка на другом компьютере через CMD

Скачайте `ChessArena.zip` из
[релиза chess-v1.0](https://github.com/platonovplaton250313-del/neon-snake/releases/download/chess-v1.0/ChessArena.zip),
распакуйте в любую папку, откройте в ней CMD и выполните:

```bat
install_chess.cmd
```

SHA-256 архива:
`43734416DAD3D71B13CBC420C8F3FB27E5F7B17E39E7357697DFE890F43E4F60`.

Установщик скопирует игру в `%LOCALAPPDATA%\ChessArena`, добавит эту папку в
пользовательский `PATH` и не попросит права администратора. После установки
закройте CMD и откройте заново (старое окно не видит новый `PATH`), затем введите:

```bat
chess
```

Удалить игру вместе с записью в `PATH`:

```bat
%LOCALAPPDATA%\ChessArena\uninstall_chess.cmd
```

Портативный вариант: `chess.cmd` работает и прямо из распакованной папки, без
установки. Если нужен совсем один файл — используйте `standalone.html`.

В репозитории установщик лежит в `chess-arena/` и сам находит веб-файлы в
`docs/chess/`, поэтому запускать его можно прямо из папки проекта.

### Сборка

Пересобрать одиночный файл после изменений в `docs/chess/`:

```bat
python chess-arena\build_chess_standalone.py
```

Скрипт вставляет CSS, движок, задачи, генератор и интерфейс в
`docs/chess/standalone.html`. Архив для установки на другом компьютере:

```bat
powershell -ExecutionPolicy Bypass -File chess-arena\build_chess_release.ps1
```

Он собирает `chess-arena\dist\ChessArena.zip` с игрой, `chess.cmd`,
`install_chess.cmd`, `uninstall_chess.cmd`, `serve_chess.ps1` и
`path_tool.ps1`. Иконки PWA пересобираются скриптом:

```bat
powershell -ExecutionPolicy Bypass -File chess-arena\build_chess_icons.ps1
```
