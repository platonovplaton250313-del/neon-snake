# С Днём Матери! — открытка на Python

Тёплая анимированная открытка-подарок на `pygame`: объёмное сердце,
акварельный фон, золотая рамка, букеты, летящие сердечки и лепестки,
мерцающие звёздочки и салют из сердечек.

Внутреннее разрешение открытки — **1600 × 1120**. На экране она
подстраивается под размер окна, а при сохранении получается большой
чистый PNG без подсказок и интерфейса.

## Как запустить

Проект лежит в папке `mothers-day/`.

1. Дважды щёлкните **`mothers-day\mothers_day.cmd`** — откроется окно с открыткой.
2. Если хочется увидеть сообщения об ошибках, запустите
   `mothers-day\mothers_day.cmd -c`.
3. Вручную:

```powershell
python -m pip install -r mothers-day\requirements.txt
python mothers-day\mothers_day.py
```

Если `pygame-ce` ещё не установлен, `mothers-day\mothers_day.cmd` предложит
установить его автоматически.

## Управление

| Клавиши | Действие |
|---|---|
| `ПРОБЕЛ` или клик | салют из сердечек |
| `S` | сохранить открытку в `mothers_day_otkrytka.png` |
| `F11` | полный экран |
| `Esc` | выход |

После нажатия `S` рядом с игрой появится готовый PNG
`mothers-day/mothers_day_otkrytka.png` — его можно отправить маме
в мессенджере или распечатать.

## Что нужно

- Python 3.9+
- `pygame-ce` 2.5+ (подойдёт и обычный `pygame`)

## Шрифты

В папке `mothers-day/assets/fonts` лежат шрифты с поддержкой кириллицы:

- **Playfair Display** — заголовок;
- **PT Serif** — основной текст и курсив;
- **Marck Script** — подпись «с любовью».

Лицензии (SIL Open Font License) находятся в
`mothers-day/assets/fonts/licenses`.
Если файлов шрифтов нет, открытка автоматически перейдёт на системные
Georgia / Constantia / Cambria.
